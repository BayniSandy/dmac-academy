========================================
DMAC ACADEMY — PWA INTEGRATION GUIDE
========================================

Add the following to the <head> of EVERY HTML page:

<!-- PWA Meta Tags -->
<meta name="theme-color" content="#CE1126">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="DMAC Academy">
<link rel="manifest" href="manifest.json">
<link rel="apple-touch-icon" href="icons/icon-192x192.png">

Add the following BEFORE </body> on EVERY HTML page:

<!-- PWA Service Worker Registration -->
<script>
if ('serviceWorker' in navigator) {
  window.addEventListener('load', function() {
    navigator.serviceWorker.register('/service-worker.js')
      .then(function(reg) { console.log('[DMAC] SW registered:', reg.scope); })
      .catch(function(err) { console.log('[DMAC] SW failed:', err); });
  });
}
</script>

========================================
FILES CREATED:
========================================
1. manifest.json         — PWA manifest (app name, icons, shortcuts, theme)
2. service-worker.js     — Caching strategies (cache-first static, network-first HTML)
3. offline.html          — Offline fallback page with DMAC branding
4. icons/icon-*.png      — 8 icon sizes (72, 96, 128, 144, 152, 192, 384, 512)

========================================
DEPLOYMENT NOTE:
========================================
When deploying to GitHub Pages, the service worker scope is root (/).
The manifest.json and service-worker.js must be in the root directory.
Icons folder must be at /icons/.

The PWA install prompt will appear automatically on Android Chrome
after the user visits twice with 5+ minutes between visits.

On iOS Safari, users tap Share → "Add to Home Screen".
